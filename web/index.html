What isn’t real

Read this before believing any pixel.

  • Showcase prices are synthetic demo data, labeled on every response.
  • Art and activity graph are illustrative procedural geometry — no neural net, no brain model, no brain data.
  • Fear/Hunt mood buttons are illustrative fiction — seeded red (fear) / blue (hunt) decorations plus cartoon loops; no real fear or hunt neurons are modeled, no neuroscience claim.
  • Signals are observations, not financial advice. Past observations imply nothing about future results.

Built in the open

Clean-room code, Python stdlib only. This is the whole machine:

  • app.py — local server, SQLite journal, JSON export
  • cat/engine.py — MA5/MA20 rule engine, warmup, activity
  • cat/providers.py — read-only price adapter, strict pair match
  • cat/showcase.py — deterministic synthetic series (labeled)
  • config.json — mode + pair (blank until our pool exists)
  • web/ — this page: vanilla HTML/CSS/JS, no dependencies
  • SPEC.md — the written spec; harnesses audit this page against it
  • tests/ — offline unit tests; run with python3 -m unittest discover -s tests -v
